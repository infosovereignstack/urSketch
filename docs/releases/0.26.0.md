# urSketch 0.26.0

Room owners get a small shield button at the lower left. Its admin dialog controls
future round length (120/150/180 seconds or 10–600 custom), resets the current
round timer, selects word banks, uploads Markdown banks, and sets a room-wide
artist difficulty with per-player overrides. Explainers use the requested lorem
ipsum placeholder copy. Resetting a timer preserves the current word and scores;
after a correct guess it also cancels that round's 20-second finish clock.

Undo reverses one complete gesture, fill, shape or clear on the host and every
viewer. The new button matches the other tools, and Ctrl/Command+Z is supported.
Only the current artist can undo, and the host validates the drawing turn token.

All completed rounds have a three-second reveal interval before the next round
or the 40-second finale. Guesses and drawing stop during this interval, while
the exact canvas remains visible. There is no gray overlay. The final canvas
clears when the fireworks sequence begins.

The most recent room is retained in the browser without an expiry. A yellow
reconnect strip below the room browser shows its name and current round from a
separate directory watch, without searching/populating the room list. Rejoining
restores the host's saved score, solved state for the current round, and place
in the drawing order. Departed players are skipped while absent and keep their
relative seats when returning. New games reset both active and absent scores.
Membership still expires after the existing two-minute heartbeat timeout;
that timeout does not delete the player's saved seat/score. Empty rooms close,
so a closed room cannot be reconnected to. Joining another room replaces the
saved destination. Reload/tab restoration never automatically joins a room.

Mobile devices automatically get a Send guess button and stacked game layout:
players/guesses at the top, canvas below, guess input at the bottom, no separate
chat. Settings → Game layout allows Automatic, Desktop or Mobile. Layout and
theme changes preserve drawing pixels and the full canvas.

Unchanged roster/message updates reuse DOM instead of recreating character SVGs;
scrollbar geometry work is batched once per animation frame. Blingee's animated
full-screen filter is removed during games, and static theme surfaces avoid
unnecessary shadows and fixed-background repainting. The focused 60-update
browser measurement is recorded in `artifacts/mobile-performance-verification.json`;
this is a DOM benchmark, not a claim about every device's frame rate.

Audio sources disconnect immediately when cancelled. Countdown ticks are bounded
short transients and cannot overlap the finale. Fireworks have an independent
wall-clock cutoff and a naturally ended voice cannot restart in a rapid loop if
the audio and wall clocks disagree. The existing 50% fireworks gain and first
20 seconds of the 40-second finale remain in effect.

[Word banks and posting verification](../WORDLISTS.md) cover the 2,000 default
and 500-entry Easy, Hard and Urbit banks. Room state upgrades from version 11
retain current drawings, scores, answers, history and player order.

# urSketch 0.27.0

Friends and DMs is available in the browser and beside How to Play, Settings,
and the room timer. Click any part of a player's row, including their cat, to
inspect their profile and request friendship. Requests pulse while work is
pending, and show approval status only after delivery has been acknowledged.

The native `%ursketch-social` agent retains requests across closed tabs and
restarts. It can notify another urSketch player before that player installs
Pals. Become Friends and Deny Friendship provide explicit consent. Requesting
or accepting installs `%pals` from `~paldev` when necessary, or revives a stopped
installation, then uses Pals' native friendship records. Requests missed by
Pals before installation are replayed after acceptance. Existing Pals list tags
are preserved. Notifications appear as a black dot beside Friends and DMs.

The friend list uses saved display names and cat portraits. Friends can inspect
one another, see their current room or Not in-game, and open a preselected DM
in their own Groups app in a new tab. This DM action assumes Groups is installed;
it does not send a message or install Groups. Room presence is shared with
friends, refreshed while connected, and expires after two minutes without an
update. The Pals explainer includes links to local Pals and its documentation.
urSketch Lounge is a disabled placeholder, pending a public Groups destination.

A Clean Slate is one shared room. The publisher's directory serializes claims
and selects the first joiner's ship as host. Other joiners receive that same
host and room. Heartbeats and bounded claims release unavailable or empty
rooms so another first joiner can host the next one. The directory is hosted
on the publisher comet; drawings and game rules remain on the chosen host.
Reaching the browser still does not automatically search for or join a room.

Rooms now admit 25 players. Games have at least ten rounds and grow to the
highest concurrent player count reached during that game. Departures do not
reduce the current game's round target. The next game recalculates that target.
Saved rooms upgrade without resetting scores, drawing order or word history.

NewRound plays when drawing ends, at the beginning of the existing three-second
artwork hold. YourTurnToDraw still plays when the next artist starts. The bottom
chat input receives focus when selected and never awards guessing points.
Close or exact answers there are hidden from other players and produce a
private warning plus CloseGuess. Normal conversation remains separate from
the Game guessing input. Saved display names and character choices restore
locally, with the ship's saved profile as a fallback.

Validation covers native capacity/peak-round/migration rules, two local-only
ships sharing one first-joiner-hosted room (including simultaneous claims),
profile persistence, private chat answers, audio timing, and real Pals install,
consent and presence flows. Test configuration uses isolated fake identities
and an isolated distributor of the official Pals source. The published config
uses the publisher comet and `~paldev`. No test friendship requests are sent to
real ships, and Pals is not proactively installed on the publisher.

# urSketch 0.27.1

The DM button now prepares the selected conversation through Groups' own
New Message flow. A bare DM URL could open Groups without creating its local
pending conversation, leaving a first-time recipient at the main/loading view.
The earlier regression checked the href alone and missed this behavior.

Clicking DM opens Groups in a new tab, filters by the friend's full Urbit ID,
selects that exact recipient and waits for the message composer. Existing
conversations and drafts are reused by Groups. The button pulses while opening,
prevents duplicate clicks and recovers after popup blocking, closure or timeout.
The Groups tab cannot access the game through window.opener. No message text
is entered and no Send control is clicked. Groups itself is not modified.

This integration uses the installed Groups client's New Message controls; future
Groups interface changes may require updating those selectors. The target is
verified from the resulting DM route and visible composer, independently of
the friend's display name.

The regression opens the real installed Groups app in disposable browser
contexts. It verifies two first-time recipients, switching recipients, reopening
a previous conversation, an empty composer, detached opener and blocked-popup
recovery. Outgoing message-action commands are blocked and counted; none occur.
Fixtures add friends only to the test page, without changing Pals records or
sending friendship requests. No private conversation screenshots are recorded.

# urSketch 0.27.3

Fix the Pals explainer link to `/pals`, its native route. When Pals is absent,
show installation guidance in place of the link. Friendship actions retain
the existing install-on-demand behavior.

Room creation is explicitly restricted to the user's own ship. It shows
progress after 30 seconds, permits a longer response window, and saves a pending
room ID across reloads for explicit retries. Repeating creation of that same
room returns it without resetting play or making a duplicate. The creator
subscribes directly, avoiding a redundant join action. The reported timeout
does not identify the cause of the original ship's stalled reply.

Game-room Friends and DMs, How to Play and Settings occupy a centered band
above the drawing tools. Saved and dragged palette positions stay below this
band and the timer. Phone layouts retain separate rows.

Archive the original 100- and 500-word banks, recovered from Git, with their
provenance. Desktop exports include these and all four current banks. Active
word banks are unchanged.

Validation includes browser layout checks across 13 themes, eight viewport/
layout combinations and both player roles, plus local creation with unavailable
remote subscriptions, a lost confirmation, an explicit retry after reload and
a response delayed beyond 30 seconds.

Installed on the publisher comet and verified through its served UI and Treaty
publication as version 0.27.3. `tests/local-room-and-header.py`, `tests/comet.py`
and `tests/live-social.py` passed against the installed release. The layout
sweep covers 208 role/theme/viewport cases; the broader canvas regression
confirms drawing remains possible along all four canvas edges. JavaScript
syntax checks and `git diff --check` passed. No Pals requests or messages were
sent by verification, and Pals was not installed as part of testing.

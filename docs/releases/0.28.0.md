# urSketch 0.28.0

The game room has one typing field. Selecting Game or Chat highlights that log
and routes Enter/Send to it without creating another input or moving the field.
Each channel retains its own draft. Chat stays usable for the artist and during
round transitions. Tab switches the destination on desktop; the phone layout
continues to use Game and its Send button. Close or exact answers entered in
Chat keep the existing private warning behavior and never score points.

Friendships requested or accepted through urSketch add the exact Pals tag
`urSketch`, preserving other Pals tags. The social agent follows tag changes in
Pals and upgrades its saved state without losing requests, profiles or room
presence. Earlier mutual friendships initiated through urSketch are tagged as
well; unrelated imported pals are not retagged.

Friends and DMs defaults to urSketch Friends, with an All Friends toggle that
removes the tag filter. Rows omit portraits and offline labels, keep names on
one line with space for 30 characters, and show a Join action only for a current
room presence. Portraits appear in View Profile. Joining a friend from another
room leaves the current room before opening the destination.

DM and the live urSketch Lounge invitation have black northeast arrows and
open in new tabs. The supplied public Lounge invitation was verified as
urSketch Lounge by ~sarhut. Local Pals links remain `/pals`, now labeled
“Open Pals app”; ships without Pals still see installation guidance.

Validation covers 52 theme/viewport name-layout cases, 208 game-header cases,
shared drafts and submission routing, canvas edge drawing and room lifecycle,
and native two-player friend Join, normal chat, private exact-answer warnings
and guessing scores. Two isolated fake ships verified exact tag spelling on
both sides, preservation of an existing Pals tag, a populated v0-state upgrade
and backfill. The test Pals desk uses the official backend and marks with only
its web frontend omitted. No test friend requests or messages reached real ships.

Installed UI checks passed on the publisher comet, including the 52 name-layout
cases and Treaty publication as 0.28.0. The previous shared-directory and
concurrent-claim integration path also passed after the separate friend-Join
path. Later manual removal of the Pals tag is respected; backfill is one-time.
JavaScript syntax checks and `git diff --check` passed.
